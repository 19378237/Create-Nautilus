# Create: Nautilus

Create: Nautilus 是面向 Minecraft 1.21.1 / NeoForge 的 Create: Aeronautics 附属模组，为船舶和潜艇加入浮力、水阻、舱室进水、供氧和机械压载系统。

模组将水下航行与 Create 的机械动力结合：船体的浸水情况、舱室空气、进水和压载会影响载具的潜浮与运动；氧气生产、储存和输送设备为密闭舱室提供供氧，气体管网与氢气设备则为推进器和锅炉提供增益。

当前发布版本：**0.1.1（早期测试版）**。

## 测试版与存档提醒

本模组仍处于早期开发阶段，可能存在崩溃、兼容性问题、物理模拟异常，以及船体、舱室数据或存档损坏风险。

- 使用、升级、回退或移除模组前，请完整备份存档，并保留可恢复的旧版本环境。
- 建议只在独立测试存档或原存档的副本中使用，不要直接在重要存档的唯一副本上测试。
- 不保证不同版本之间的船体、舱室与存档数据能够无损迁移或回退。
- 当前适配的光影包括 **Photon、Bliss 和 Complementary Unbound**。推荐使用 **Photon v1.3a**，当前水体与水下视觉效果以该版本表现最佳。具体兼容性仍需结合光影版本、渲染模组及整合包的实际组合确认。

## 模组内容

- **浮力与水阻**：根据载具浸水情况、舱室空气和进水量计算浮力、阻力与推进表现。
- **舱室与进水**：检测内部舱室和船体开口，处理进水、舱内水量及压力变化，并呈现舱内水体。
- **氧气系统**：支持密闭舱室氧气储存与消耗，提供电解制氧机、机械通气管和氧气接口。
- **压载控制**：通过机械动力调节前、后舱水量，改变载具的配重与潜浮状态。
- **气体与氢气设备**：提供储罐、管道、气泵、压缩机、减压阀和紧急排空设备，支持气体输送与氢气增压，并包含氢气储存风险机制。
- **显示与渲染**：支持工程师护目镜容量信息、中英文语言，以及 Iris / Sodium 相关水体渲染适配。

当前版本尚未内置设备合成配方，也不模拟舱内水体晃荡。

## 相较上一发布版的改动

以下以首个公开发布包为对照，按功能合并列出改动；同一功能涉及的多处代码调整不重复计数。

### 变更

- **依赖基线**：NeoForge 21.1.228 → 21.1.248，Sable 2.0.3 → 2.0.6，Create: Aeronautics 1.3.0 → 1.3.2，Veil 编译接口 4.1.4 → 4.3.2；Minecraft 1.21.1 和 Create 6.0.10 保持不变。
- **开口换气规则**：内外等压时，未被水封住的开口仍能置换舱内空气；仅干燥开口面积参与换气。
- **舱室存档与旧档迁移**：保存精确成员格、真实源水占用格及待处理船壳变化，临时卸载时保留形状与库存。旧存档缺少精确形状且无法唯一匹配时，会丢弃对应旧舱室及库存并重新扫描，因此不保证无损升级。
- **舱室分割合并规则**：水量优先保留在原有湿润位置，被挤出的水在对应连通组内按剩余容量分配；气体和氧气按干燥空间分配。原舱室身份优先交给重叠最多的部分，新舱室使用唯一 ID。
- **推进效率采样模型**：由整船浸水比例改为推进器叶片实际扫掠区域采样，区分真实船内水、虚拟舱水及外部水体；组装推进器按各叶片层扫掠面积加权，并排除实体隔膜遮挡。
- **机械通气管进气条件**：入口不仅需要无水，还须沿开放空间连通天空；密闭空气袋和船内空气不能作为无限气源。
- **发布源码清理**：移除全部自定义验证脚本、测试夹具和相关构建任务，保留正常编译打包入口；清理未接入的旧水体过渡绘制代码。

### 修复

- **舱室浮力**：修正重叠、嵌套船体的排水体积，扣除其他船体实体及优先所属舱室占用的空间，同时调整浮力作用位置，避免重复计入排水体积。
- **真实水与虚拟水**：真实完整水源格不再重复占用虚拟水容量；压力、进水、质量、浮力与客户端水面使用一致的水域划分。水质量按当前物理子步同步，零容量舱室的同步及 API 比例返回零。
- **实体接触水体**：由中心点或脚部点改为完整身体与实际舱格接触判定，处理倾斜船体、舱室边缘和部分浸水；只扣除被舱室覆盖的外部海水，保留其他身体部位接触的外水、真实船内流体和水流，并同步身体、眼部水类型及游泳状态。
- **氧气与呼吸**：创造、旁观和无敌玩家不再消耗舱室氧气；实际眼部非水流体保留自身呼吸规则，水下呼吸、附魔与溺水处理继续交给 NeoForge。
- **高压舱室库存**：读档、几何更新和外界进气不再把压缩氧气截到常压名义容量；库存超过名义容量时，新增氧气的接受量不会成为负数。
- **船壳变化提交**：按方块最终状态处理破口，不再因被取消、回滚的放置或破坏提前改变库存与拓扑；覆盖直接替换成水或非碰撞方块的情况，并避免组装搬运产生临时破口。
- **厚船壳与多格破口**：将连续受损格作为通道识别，保留真正朝外的口部，处理多个舱室共用外口、破口连通合舱，以及修复或外加装甲后的几何重建。
- **多破口穿流**：容量或平衡限制只缩减无法接受的净流量；即使净进水量为零，也保留能够互相抵消的进出水反馈。
- **扫描未完成的处理**：区分空拓扑、区块未就绪和超过扫描上限；后两种情况保留已有库存，延后重试并限频记录原因，不直接当作空舱处理。
- **同步数据校验**：拒绝重复舱室 ID、非有限或无效边界、越界成员格及非有限水位，避免异常数据进入客户端缓存。
- **玩家重新跟踪**：重生、换维度和退出时清理舱室与干燥遮蔽跟踪记录，修正相同玩家 UUID 返回后无法重新收到状态的问题。
- **电解制氧机取水**：进水侧必须可通过、已加载且不属于已记录舱室，避免隔墙取水或把有限舱水当作无限外水。
- **设备气口刷新**：电解制氧机、氧气接口、压缩机、减压阀、紧急排空阀及两类氢增压器转向后，及时更新气口能力与连接方向。
- **气泵流量与抽取顺序**：保存不足 1 mB 的流量余量，低转速按转速线性输送；堵塞或断供不积攒突发额度。轮换多个来源，检查来源中的多个储气槽，并区分同设备不同面的独立库存。
- **气泵输送守恒**：实际接收少于预演时，已抽取但未送达的气体保留在泵内、优先补送并写入存档，避免余气丢失。
- **气罐合并**：合并各层时统一检查气体及组件，空控制器也能正确确定气体类型；无法完整接收时恢复库存，避免混气与合并丢气。
- **气罐读档与液位**：按气罐实际容量恢复原始库存，修正超出 Create 原生容量部分被截断的问题，并更新客户端液位；气口直接访问真实控制器库存。
- **气罐原生模式**：清除不适用的 Create 锅炉和汽笛状态，防止气罐误用原生水锅炉行为。
- **孤立气管方向**：邻居变化和定时刷新保留已有连接方向，不再被更新来源或固定北向重置。
- **紧急排空阀**：在总排放预算内继续处理其他相邻气源，不再只排第一个来源；实际抽取匹配预演的具体气体。
- **氢增压燃料**：两类氢增压器只有在库存足够支付完整用量时才扣除燃料；断供不提前抽走部分燃料，也不积累欠燃料额度。
- **推进器氢增压目标**：只绑定正在运行且达到工作转速的推进器，记录并同步实际目标；停用或移除增压器后清理增益来源，避免增益显示到相邻其他推进器。
- **锅炉氢增压**：采用 Create / Sable 实际未增压热源扫描，包含载具外部热源；处理被动热状态、热量变化同步，以及转向后新旧锅炉的温度刷新。
- **氢罐直接破坏**：实际方块移除生效后才触发破裂，保留拆分前的完整压力容器状态，并保留触发位置已经提交的替换方块，避免取消破坏仍触发爆炸。
- **外部爆炸命中**：仅破坏型爆炸可触发氢罐破裂，使用 Sable 给出的实际命中列表，不再重复投影或用邻格推定命中，避免误炸未被实际破坏的气罐。
- **无光影遮海水范围**：沿船体本地轴外扩一格，并过滤真实船内水；船体移动、旋转或范围变化后刷新新旧世界区段。Sable 相机与近深度清理使用一致的连续干区，保留其他模组注册的遮蔽区域。
- **Sodium 精确遮水**：无光影路径也使用逐片元体素图集；近远深度补充未覆盖区域，图集、位置或绑定不可用时回退完整深度遮挡。使用本次绘制矩阵，切换世界或管线时清理旧矩阵。
- **进水舱的外海去重**：父世界海水裁剪覆盖整个舱体，包括部分和完全进水区域，避免进水后海水几何重新进入舱内；真实船内水继续保留原生渲染。
- **相机介质与雾色**：分别采样真实水、虚拟水及近裁面的岩浆和细雪，真实介质优先；无光影保留原版雾色，Sable 绘制湿舱方块时保留水雾，实体判定不套用相机边界余量。
- **客户端水域刷新**：方块变化、整块区块数据载入或卸载时定向失效相关水域；未知区块不直接当作干舱。长期稳定水位再次变化时，仅在最近一个 tick 范围插值，不跨越整段收包静默时间。
- **虚拟水绘制阶段**：分开绘制可见水面与雾效深度外壳，调整至 Sable 玻璃之后提交；修正真实海水视角下漏绘及 Photon 湿舱场景、玻璃深度处理，使用当前绘制阶段矩阵，并允许临时绘制失败后重试。
- **水面排序与精度**：对每次提交的虚拟水透明三角形按距离排序；顶点先减去相机位置再转为浮点数，降低远坐标精度损失。此项不代表解决所有原生玻璃交错排序。
- **薄玻璃与动态模型**：光学事件记录实际玻璃面位置，匹配及角点恢复均校验该面；即使 BlockState 未变，模型数据更新也会刷新相关遮水几何缓存。
- **已有光影补丁**：只匹配可执行 GLSL，避免注释或多个不明确入口误匹配；调整 Photon 的 LPV、解析雾和材质源码布局适配，兼容 Veil 输出的表达式括号，并调整渲染比例下的 UV 与像素覆盖容差。
- **Iris 采样器**：提前给私有整数、浮点采样器分配合法且不冲突的纹理单元，即使适配尚未启用也保持有效绑定。
- **光影资源生命周期**：缓存维度管线保留对应适配代次，销毁时释放；编译、链接或上传失败时清理半成品，分辨率由超预算恢复后允许重新尝试。精确水体路径的版本检查同步至当前 Sable、Sodium 和 Colorwheel 基线。
- **体积数值稳定性**：调整近水平、近轴对齐姿态的裁剪体积公式，减少近似值相减造成的数值误差；并非本次才支持倾斜船体水面。
- **动力效果与气泡**：按实际液面识别真实船内水及虚拟进水，已知干舱不再因外部海水触发水下效果；推进器尾流气泡能够在对应舱内水域继续存在，复用原版气泡外观与运动。

### 优化

- **船体扫描**：跳过全空气区段，减少空范围遍历；原生区段视图不可用时保留普通世界查询回退。
- **外水与破口采样**：同一物理子步内共享水体、区块和破口水位/气压结果，对相同水柱去重；不主动加载未知区块，自定义流体保留自身高度查询规则。
- **舱室几何求解**：形状和姿态不变时复用投影准备结果，只有水量变化时仅重新求水面；进水、浮力、遮蔽和水质量中心共用结果，并按姿态或形状变化失效。
- **稳定状态复用**：未变化的舱室扫描复用原状态，真实源水使用不可变测量快照，避免重复复制和质量注入；遮蔽格使用排序去重数据，仅视觉水线变化时复用物理遮蔽注册。
- **网络发送**：按实际传输精度比较水位，干燥遮蔽不再每秒重复发送；仍向新增跟踪玩家补发，排空后明确发送零水位。
- **推进器计算与显示**：服务器主线程集中采样，物理推力钩子读取缓存；客户端使用服务器同步的浸水率和最终倍率，只在值变化时发送更新。
- **大型气路搜索**：节点首次入队即去重；超过搜索上限时停止整次输送并限频记录，避免使用截断的部分网络继续运行。
- **连锁氢爆**：改为分 tick 队列处理，每 tick 最多处理 32 次，并对同一压力容器去重，避免递归连爆集中处理。
- **氢系统记录清理**：碰撞记录设置数量上限并定期过期，维度卸载或服务器停止时清除碰撞、增压关联和待处理爆炸，减少残留引用。
- **渲染帧快照**：水体快照按实际渲染帧复用，替代固定 33 ms 缓存，避免不同渲染帧共用过期水位快照。
- **水面与网格缓存**：复用稳定水面、拓扑、边界关系和世界角点；限制缓存数量及体素量，并在源水、区块、资源或世界变化时清理。
- **GPU 局部上传**：合并相邻变化区间，变化过多时才上传整段；只暂存选中数据，上传成功后更新缓存，部分失败时下次重新上传。
- **图集布局**：距离仅决定预算选择，驻留船体按 UUID 保持稳定布局，避免相机经过等距位置时反复重排；无光影路径不求解不需要的精确水面。
- **遮罩与默认诊断开销**：剔除完全位于视点后方的有效光学盒，近裁面情况仍保守处理；周期日志降为 DEBUG，像素回读改为显式开启，回读失败后不再每帧重试。
- **压载界面本地化**：前后舱百分比改用翻译文本，中文显示“前舱”“后舱”；按钮和数值操作逻辑保持不变。

### 新增

- **氧气接口六向朝向**：支持六向放置、旋转、镜像及扳手调整，模型同步朝向；向可见出口正前方舱格供氧，出口正面不作为气管输入面，其余面可接入。
- **跨船体库存迁移**：支持既有船体分裂、二次组装流程中的水、气体、氧气、破口与舱室形状迁移；等待相关船体就绪后联合分配，并保存未完成迁移以便卸载、重载或后续分裂时继续处理，避免重复通知复制库存。此项不是新增组装方块或新组装玩法。
- **船体自然积雪选项**：新增 `weather.preventNaturalSnowOnCarriers`，默认开启，阻止物理载具上自然雪层生成或增厚；覆盖原版降雪及对应 ByePregen 调用，不影响已有积雪、手动放置和结冰。
- **光影水下雾选项**：新增 `rendering.shaderUnderwaterFogEnabled`，默认开启，控制本地客户端的 Nautilus 光影水下雾集成，不改变水体物理或世界天气。
- **Create: Prism 玻璃机壳适配**：补充钢制玻璃机壳识别，并为六类玻璃机壳提供不透明框架深度适配；仅调整符合条件的模型，保留不符合条件的资源包替换，不新增 Prism 硬性依赖。
- **可选运行性能诊断**：新增服务端水体查询、缓存与扫描统计，客户端水体工作量、帧耗时、线程 CPU/分配及分阶段 GPU 时间戳统计；默认关闭，GPU 结果就绪后才读取，不主动等待，并补充同一采样时刻的浮力运动调试信息。
- **注册状态调试日志**：增加 Create 关键物品及 Holder 注册状态的 DEBUG 信息，用于定位启动注册问题，不代表新增这些物品。

### 总结

本次更新修复了若干 Bug。相较上一发布版本，测试场景下综合性能提升约 **25%**；实际收益会随场景、船体规模、硬件和模组组合变化。

本版本为早期测试版本，使用、更新、回退或移除模组前，请完整备份存档。

- Minecraft **1.21.1**，Java **21**。
- NeoForge 构建基线 **21.1.248**。
- Create 构建基线 **6.0.10**。
- Sable 构建基线 **2.0.6**。
- Create: Aeronautics / Simulated 构建基线 **1.3.2**。

加载器允许的版本范围见 `src/main/resources/META-INF/neoforge.mods.toml`；范围内其他版本不代表已经验证兼容。Iris、Sodium 和 JEI 为可选组件，不随本模组打包。

## 从源码构建

使用 JDK 21，在项目根目录执行：

```powershell
.\gradlew.bat build --no-daemon --console=plain
```

Linux / macOS 使用 `bash ./gradlew build --no-daemon --console=plain`。首次构建需要联网下载依赖，产物位于 `build/libs/`：`create_nautilus-0.1.1.jar` 为模组，`*-sources.jar` 为源码包。

## 项目结构

- `src/main/java/`：模组源码。
- `src/main/resources/`：模型、贴图、语言文件与模组数据。
- `build.gradle`、`settings.gradle`、`gradle.properties`：构建、依赖与版本配置。
- `gradlew`、`gradlew.bat`、`gradle/wrapper/`：Gradle Wrapper。
